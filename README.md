# FilmmakingUI — espejo de descargas

Copia estática de https://filmmakingui.com (landing y descarga) para cuando la web principal no carga. Los instaladores están en [Releases](../../releases) con el mismo SHA-256 que en la web principal (ver `latest.json`).

Se genera con `tools/espejo_web.py` en el repositorio de la app; no edites aquí a mano.
