Instalar FilmmakingUI en Windows

Qué descargar, cómo pasar el aviso de SmartScreen y qué hacer si tu equipo tiene Smart App Control activo.

  1. Qué descargar
  2. El aviso «Windows protegió su PC» (SmartScreen)
  3. ¿Tengo Smart App Control activo?
  4. Versión portable de respaldo
  5. Tus datos y la desinstalación

1. Qué descargar

RECOMENDADO

Instalador

FilmmakingUI-…-windows-x64-setup.exe. Se instala solo para tu usuario, sin permisos de administrador. Si Windows muestra un aviso azul, sigue la sección 2.

SI TIENES SMART APP CONTROL

Portable de respaldo

FilmmakingUI-…-windows-x64-portable.zip. Funciona aunque Smart App Control esté activo. Ver la sección 4.

¿No sabes cuál te toca? Mira primero si tienes Smart App Control activo: si lo está, usa la portable; si no, el instalador.

2. El aviso «Windows protegió su PC»

Windows muestra este aviso con los programas nuevos que aún no conoce. Es normal en las primeras versiones de FilmmakingUI. Para continuar:

  1. Haz clic en Más información.
  2. Comprueba que la aplicación es FilmmakingUI-…-setup.exe y que la descargaste desde nuestra web.
  3. Haz clic en Ejecutar de todas formas.
Si en lugar de este aviso ves que Smart App Control bloqueó el archivo y no aparece «Más información» ni «Ejecutar de todas formas», no hay forma de saltarlo: usa la portable de respaldo.

3. ¿Tengo Smart App Control activo?

Smart App Control viene activado en algunas instalaciones nuevas de Windows 11. Bloquea los programas que no están firmados o que Windows aún no conoce, sin dar la opción de ejecutarlos igualmente.

Comprobarlo desde Configuración

  1. Abre Seguridad de Windows (búscalo en el menú Inicio).
  2. Entra en Control de aplicaciones y navegador.
  3. Pulsa Configuración de Smart App Control y mira qué opción está marcada.

O con un comando

Abre PowerShell y escribe:

PS> (Get-MpComputerStatus).SmartAppControlState
On

On = activado (usa la portable). Eval = en evaluación. Off = desactivado.

No te recomendamos desactivar Smart App Control para instalar FilmmakingUI: una vez desactivado, Windows no permite volver a activarlo sin reinstalar el sistema. La portable de respaldo existe precisamente para no tener que hacerlo.

4. Versión portable de respaldo

Arranca con el Python oficial, firmado por la Python Software Foundation, que Smart App Control sí permite. Funciona igual que la versión instalada.

  1. Descarga FilmmakingUI-…-windows-x64-portable.zip.
  2. Haz clic derecho → Extraer todo… y elige una carpeta, por ejemplo Documentos\FilmmakingUI.
  3. Abre FilmmakingUI.bat. La primera vez se abre el navegador para crear tu usuario y contraseña.
  4. Si Editar imagen, Editar vídeo o Secuencia avisan de que falta ffmpeg, abre Instalar ffmpeg.bat una vez (usa winget, el instalador de Microsoft) y vuelve a abrir FilmmakingUI.

5. Tus datos y la desinstalación

  • Proyectos, galería, personajes, ubicaciones, props, keys cifradas y ajustes se guardan en %APPDATA%\FilmmakingUI. Los comparten el instalador, la portable y la versión de Microsoft Store.
  • Al desinstalar, Windows pregunta si borrar también tus datos. La respuesta por defecto es No: si vuelves a instalar, FilmmakingUI los retoma sin pedirte crear el usuario otra vez.
  • Si tenías una instalación anterior en C:\AI\FILMMAKING_PIPELINE, la primera vez que abras la nueva versión te ofrecerá copiar tus proyectos. Solo se copian: la carpeta antigua no se modifica.
