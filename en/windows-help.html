Install FilmmakingUI on Windows

What to download, how to get past the SmartScreen warning and what to do if your computer has Smart App Control turned on.

1. What to download

RECOMMENDED

Installer

FilmmakingUI-…-windows-x64-setup.exe. It installs for your user only, without administrator rights. If Windows shows a blue warning, follow section 2.

IF YOU HAVE SMART APP CONTROL

Fallback portable

FilmmakingUI-…-windows-x64-portable.zip. It works even with Smart App Control turned on. See section 4.

Not sure which one you need? First check whether Smart App Control is on: if it is, use the portable; if not, the installer.

2. The «Windows protected your PC» warning

Windows shows this warning for new programs it does not know yet. It is normal for the first versions of FilmmakingUI. To continue:

  1. Click More info.
  2. Check that the app is FilmmakingUI-…-setup.exe and that you downloaded it from our website.
  3. Click Run anyway.
If instead of this warning you see that Smart App Control blocked the file and there is no «More info» or «Run anyway», there is no way around it: use the fallback portable.

3. Is Smart App Control turned on?

Smart App Control comes turned on in some new Windows 11 installations. It blocks programs that are not signed or that Windows does not know yet, without offering to run them anyway.

Check it in Settings

  1. Open Windows Security (search for it in the Start menu).
  2. Go to App & browser control.
  3. Click Smart App Control settings and see which option is selected.

Or with a command

Open PowerShell and type:

PS> (Get-MpComputerStatus).SmartAppControlState
On

On = turned on (use the portable). Eval = in evaluation. Off = turned off.

We do not recommend turning off Smart App Control to install FilmmakingUI: once it is off, Windows does not let you turn it back on without reinstalling the system. The fallback portable exists precisely so you don't have to.

4. Fallback portable version

It starts with the official Python, signed by the Python Software Foundation, which Smart App Control does allow. It works just like the installed version.

  1. Download FilmmakingUI-…-windows-x64-portable.zip.
  2. Right-click → Extract All… and choose a folder, for example Documents\FilmmakingUI.
  3. Open FilmmakingUI.bat. The first time, the browser opens so you can create your username and password.
  4. If Edit image, Edit video or Continuous sequence warn that ffmpeg is missing, open Instalar ffmpeg.bat once (it uses winget, Microsoft's installer) and open FilmmakingUI again.

5. Your data and uninstalling

  • Projects, gallery, characters, locations, props, encrypted keys and settings are stored in %APPDATA%\FilmmakingUI. The installer, the portable and the Microsoft Store version share them.
  • When you uninstall, Windows asks whether to delete your data too. The default answer is No: if you install again, FilmmakingUI picks it up without asking you to create the user again.
  • If you had a previous installation in C:\AI\FILMMAKING_PIPELINE, the first time you open the new version it will offer to copy your projects. They are only copied: the old folder is not modified.
