Install on Windows

  1. Download the installer and open it.
  2. If Windows shows «Windows protected your PC» (SmartScreen), click «More info» and then «Run anyway». It is normal for new programs: the installer does not have the reputation that only time gives yet.
  3. Follow the installer steps and open FilmmakingUI.

If Windows blocks the installer (Smart App Control)

  • Smart App Control, when it is on, blocks unsigned programs and does not offer «Run anyway».
  • In that case use the portable version: unzip it into a folder of yours (for example, Documents) and open FilmmakingUI.bat. It needs no installation.
  • You can also turn Smart App Control off in Windows Security → App & browser control; note that once it is off, Windows does not let you turn it back on without reinstalling.

Install on Mac

  1. Open the .dmg and drag FilmmakingUI into Applications.
  2. The app is not signed by Apple: the first time, right-click it → Open → Open. If macOS blocks it, go to System Settings → Privacy & Security and click «Open Anyway».
  3. For Transform video and Sequence you need ffmpeg: install Homebrew and run «brew install ffmpeg».

Activate the license

  1. Open FilmmakingUI: if there is no active license, the license screen appears. Click «Start 7-day free trial» to try it without paying (one trial per computer; no key or email needed).
  2. To carry on, buy a license (First month, Monthly or Annual): you will receive the key by email from the store.
  3. Paste the key and click «Activate». An internet connection is only needed to activate and to check it (every 7 days; it works 14 days offline).
  4. The key works on 2 computers. To move it to another one, use Settings → License → «Deactivate this computer».
  5. If you change plan (from the First month or the Monthly to the Annual, or you renew the Monthly), activate the new key on the same computer: it replaces the previous one and your remaining days are added.
  6. When the trial ends or the license expires, the license screen shows the plans with their link to the store; your projects and data stay on your computer.
