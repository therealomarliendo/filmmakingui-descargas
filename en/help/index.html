Quick start

FilmmakingUI is an AI film production studio that runs on your computer. You generate images and videos with models from fal, Higgsfield, ByteDance and other providers using your own keys (BYOK): you pay each provider only for what you generate.

1. Install

  • Windows: download the installer (…-windows-x64-setup.exe). If Windows shows «Windows protected your PC», click «More info» → «Run anyway». With Smart App Control turned on, use the portable version (see Install on Windows).
  • Mac: open the .dmg and drag FilmmakingUI to Applications. The first time, if macOS blocks it, go to System Settings → Privacy & Security → «Open Anyway». For Transform video and Sequence, install ffmpeg with Homebrew (brew install ffmpeg).

2. First launch

  1. The browser opens the setup wizard: choose the language, create your username and password and, if you have a license, paste the key (you can do it later).
  2. The last step asks only for the fal.ai key, with a step-by-step guide: create your fal.ai account, add credit, create the key in Dashboard → Keys, paste it, click Test key (it is free) and Save and start. With it you generate images, video and voice, and Claude writes the texts («Claude through fal» engine, the default one).
  3. The other keys (Anthropic, ElevenLabs, Higgsfield, ByteDance) are optional: add them whenever you like in Settings → API keys. They are stored encrypted on your computer and never leave it except to go to their own provider.

7-day free trial

With no license, the License screen offers Start 7-day free trial: every feature for 7 days on that computer, with no card, no payment and no email asked. There is one trial per computer. When it ends, the same screen shows the plans; your projects and data stay intact.

Activating your license

If you bought a license (First month, Monthly or Annual), the store emails you the key. If a person gave it to you, it looks like FMUI-XXXX-XXXX-XXXX-XXXX. Either way:

  1. When you open the program you will see the License screen. Paste the key and click Activate. If you had already created your user, the screen appears by itself on login; in the setup wizard, the key goes in the same form.
  2. You only need an internet connection to activate and to check it (it checks itself every 7 days and, offline, the program keeps working for 14 days).
  3. Your projects, keys and settings are not touched: the license only allows the program to open or not.
  4. Each license allows a number of computers (the one you were given). To move it to another, use Settings → License → Deactivate this computer on the first one.
  5. Purchased licenses expire (30 days for the First month and the Monthly, 1 year for the Annual) and do not renew by themselves: when one expires, the license screen shows the plans with their link to the store and your projects and data stay intact. The First month (€9.99, discounted) is only offered if you have never had a paid license; the Monthly and the Annual, always. When you change plan (from the First month or the Monthly to the Annual, or when you renew the Monthly), activate the new key on the same computer: it replaces the previous one and your remaining days are added.
  6. If the message says the license is blocked or that it is not available from your location, write to whoever gave it to you: your data stays intact and it works again as soon as it is sorted out. If you use a VPN, turn it off and click Check now.

3. Your first image

  1. Open Film, click + New project, name it and choose live action or animation and the orientation.
  2. In Single shot, describe the action in English (for example, a woman reads a letter by the window).
  3. Pick characters, a location or props from your library (optional) and the image model.
  4. Click Generate shot: the button shows the estimated cost. Above the Settings threshold it asks for confirmation.

4. Next steps

  • Create reusable characters in Library → Characters so they look the same in every shot.
  • Turn a whole script into scenes and shots with Script to Storyboard.
  • Animate a shot from its card in the gallery, or create a long video in Sequence.
  • Every section has a guided tutorial: click ? at the top right.

Costs

Every button that spends money shows the estimated cost before anything is sent. What you spend appears in the project's spending chip and in «Session» (bottom left). Prices are the ones each provider publishes; Higgsfield does not publish them, so they are estimated from real generations.
