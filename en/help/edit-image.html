Edit image

Change an image with a prompt and, if you like, with reference images.

  1. Image to edit: upload it, choose it from a gallery, extract a frame from a video or generate a new one.
  2. References: characters or images; their label («person on the left») can be used in the prompt.
  3. Model: each one accepts a maximum number of images; GPT Image charges for every image sent.
  4. Aspect ratio: «Same as the original» uses the closest one the model supports.
  5. Edit prompt (in English). «See the prompt that will be sent» shows how each image is numbered.
  6. Optional: apply the style of an animation project.
  7. Edit shows the cost. The result is a new image: the original is never overwritten.

From the result you can view before/after, report it or use it in Transform video (Motion control).
