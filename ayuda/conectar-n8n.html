Conectar n8n (API para automatizaciones)

FilmmakingUI trae una API local para que n8n, Make, Zapier o un script generen imágenes, vídeos y montajes sin abrir la interfaz. Usa tus propias keys (lo que se gasta lo cobra el proveedor, no FilmmakingUI) y está pensada para producir, por ejemplo, vídeos verticales en serie desde una hoja de cálculo.

Verlo en 1 minuto

La forma más rápida: en Ajustes → API para automatizaciones pulsa el botón grande «Conectar n8n en 3 pasos» y sigue el asistente (crea tu token con valores seguros, descarga el flujo y te dice dónde pegarlo). El resto de esta guía explica lo mismo con más detalle.

Antes de empezar

  • Hace falta la licencia activa (la API también está en la prueba de 7 días) y que la app esté abierta en el equipo donde corre.
  • La API está desactivada por defecto. Se activa en Ajustes → API para automatizaciones.
  • Es un servidor aparte (puerto 8780) que, salvo que lo cambies, solo escucha en tu equipo (127.0.0.1).

1. Crear tu token (lo hace el asistente)

El botón «Conectar n8n en 3 pasos» activa la API, permite el gasto (con un aviso) y crea un token que puede gastar créditos hasta $2 al día y caduca en 30 días. Si prefieres hacerlo a mano:

  1. Ajustes → API para automatizaciones → marca la casilla para activarla.
  2. Si el flujo va a generar (y no solo leer o montar), marca Permitir gasto por API y confirma el aviso.
  3. Crear un token nuevo: nombre (por ejemplo «n8n vídeos»), alcance Gasto, tope diario (por defecto $5) y, si quieres, caducidad y las IP desde las que se puede usar.
  4. Copia el token y el secreto de webhook ahora: solo se muestran una vez. Si lo pierdes, revócalo y crea otro.

El token es como una contraseña: no lo pegues en chats, capturas ni flujos que compartas. Puedes revocarlo cuando quieras en la misma pantalla.

2. Reglas de gasto (para que no haya sorpresas)

  • Cada petición que gasta exige max_cost (USD): si la estimación lo supera, se rechaza sin generar nada.
  • Cada token tiene un tope diario; al llegar a él, la API responde 402 daily_cap_exceeded.
  • Las peticiones de pago exigen la cabecera Idempotency-Key (de 8 a 64 caracteres: letras, números, _ - : .): si n8n reintenta, no se cobra dos veces.
  • El interruptor global de seguridad y tu licencia siguen mandando. Los montajes con plantilla son gratis (ffmpeg local).
  • Lo generado aparece en la Galería con el origen «API · nombre del token».

3a. n8n en el mismo equipo (localhost)

Es lo más sencillo y lo más seguro.

  1. Importa el flujo de ejemplo: en n8n, Workflows → Import from file → docs/ejemplos/n8n_videos_virales.json (está en la carpeta de FilmmakingUI; también en https://filmmakingui.com/ejemplos/n8n_videos_virales.json).
  2. Abre el nodo Configuración y pega tu token en api_token. Deja api_base como http://127.0.0.1:8780/api/v1.
  3. En los nodos de Google (Sheets y Drive) elige tus credenciales. Si no quieres Drive, desactiva el nodo Subir a Drive: el enlace será el de la API.
  4. Crea la hoja Ideas con estas columnas: tema, guion corto, formato (9:16, 16:9 o 1:1), max_cost, estado, video_url, coste_real, coste_estimado, job_id, notas. Una fila = una idea, con estado = pendiente.
  5. Pulsa Ejecutar a mano. Por cada fila el flujo: estima el coste → si cabe en max_cost, crea 3 imágenes → las anima a vídeo → monta un vídeo vertical con la plantilla UGC/TikTok y subtítulos del guion → recibe el webhook → escribe en la hoja el enlace, el coste y el estado.
  6. Para que corra solo, activa el flujo (se ejecuta cada 10 minutos sobre las filas «pendiente»).

Coste de una fila de prueba (3 imágenes FLUX.2 Flash + 3 clips de 4 s de MiniMax H3 Max Turbo a 480p): unos $0,33 estimados (menos mientras dure la promoción de H3 Max Turbo). Pon un max_cost de 0,5 para esa fila.

Si n8n va en Docker: dentro del contenedor 127.0.0.1 es el propio contenedor. Ejecuta n8n fuera de Docker o usa el túnel de la sección siguiente.

3b. n8n en otro equipo o en n8n Cloud (con tu Cloudflare Tunnel)

n8n Cloud, Make y Zapier están en Internet y no pueden llegar a 127.0.0.1. La forma segura es un túnel HTTPS de Cloudflare hacia tu equipo (gratis; necesitas una cuenta de Cloudflare y un dominio en ella).

Avisos de seguridad antes de abrir nada - Usa siempre HTTPS (el túnel lo da). Nunca expongas el puerto 8780 directamente a Internet ni abras el router. - Crea un token dedicado para esta conexión, con tope diario bajo y caducidad. No uses el mismo token para otras cosas. - Si puedes, restringe el token por IP (n8n Cloud publica sus IP) y protege el túnel con Cloudflare Access (token de servicio) como segunda barrera. - Mientras el túnel esté activo, cualquiera con tu token puede gastar con tus keys hasta el tope diario: guárdalo como una contraseña y revócalo si dudas. - El equipo tiene que estar encendido y con FilmmakingUI abierto.

Pasos (Windows):

  1. Instala cloudflared: winget install Cloudflare.cloudflared.
  2. Prueba rápida (temporal): cloudflared tunnel --url http://127.0.0.1:8780 te da una dirección https://algo.trycloudflare.com que cambia cada vez. Sirve para probar, no para producción.
  3. Túnel permanente: `` tunnel: filmmakingui-api credentials-file: C:\Users\TU_USUARIO\.cloudflared\<ID>.json ingress: service: http://127.0.0.1:8780 ``
    • cloudflared tunnel login (elige tu dominio).
    • cloudflared tunnel create filmmakingui-api.
    • cloudflared tunnel route dns filmmakingui-api api.tudominio.com.
    • Crea config.yml (en %USERPROFILE%\.cloudflared) con:
    • hostname: api.tudominio.com
    • service: http_status:404
    • cloudflared tunnel run filmmakingui-api (o instálalo como servicio: cloudflared service install).
  4. En FilmmakingUI, Ajustes → API, escribe api.tudominio.com en Dominio de tu túnel. La API sigue escuchando solo en 127.0.0.1: el túnel entra por ahí. (La casilla «Permitir acceso remoto» abre el puerto a toda tu red: no la necesitas con un túnel en el mismo equipo.)
  5. En n8n pon api_base = https://api.tudominio.com/api/v1 y tu token. Los webhooks de vuelta funcionan igual: n8n da una URL pública ($execution.resumeUrl) y FilmmakingUI la llama con una firma.
  6. Comprueba: curl https://api.tudominio.com/api/v1/ping debe responder {"ok":true,...} y curl -H "Authorization: Bearer TU_TOKEN" https://api.tudominio.com/api/v1/health, tus datos.

Webhooks firmados

Al terminar un trabajo, la API hace un POST a la URL que pongas en webhook.url con una firma HMAC-SHA256 en la cabecera X-FilmmakingUI-Signature (t=<unix>,v1=<hex>), calculada con el secreto de webhook del token sobre "<t>." + cuerpo. Compruébala en tu receptor y rechaza lo que tenga más de 5 minutos. Si tu receptor responde con error, se reintenta hasta 5 veces. Hacia Internet el webhook debe ser https; http solo se admite hacia tu equipo o tu red local (n8n local).

Referencia rápida

Documentación completa y probador en http://127.0.0.1:8780/api/docs (Swagger, funciona sin Internet): pulsa Authorize, pega tu token y usa Try it out en /estimates o /jobs, que ya traen un ejemplo listo (imagen FLUX.2 Flash 9:16, máximo $0,05).

QuéPetición
Modelos y preciosGET /api/v1/models?type=video
Estimar sin generarPOST /api/v1/estimates
Crear un trabajoPOST /api/v1/jobs (type: image, video, lipsync, voice, montage; max_cost; cabecera Idempotency-Key)
Estado y resultadoGET /api/v1/jobs/{id} y GET /api/v1/jobs/{id}/files/1
Subir una imagen de entradaPOST /api/v1/files (multipart)
Galería, personajes, ubicaciones, propsGET /api/v1/gallery, /characters, /locations, /props
Gasto de hoyGET /api/v1/usage

Ejemplo (una imagen vertical, con tope de $0,05):

curl -X POST http://127.0.0.1:8780/api/v1/jobs ^
  -H "Authorization: Bearer TU_TOKEN" -H "Idempotency-Key: mi-primera-imagen-001" -H "Content-Type: application/json" ^
  -d "{\"type\":\"image\",\"model\":\"fal-ai/flux-2/flash\",\"max_cost\":0.05,\"params\":{\"prompt\":\"un faro al amanecer\",\"aspect_ratio\":\"9:16\"}}"

Errores frecuentes

CódigoQué significa
401 unauthorizedFalta el token o no es válido (¿revocado, caducado o con una IP no permitida?).
403 spend_not_allowedActiva «Permitir gasto por API» y usa un token con alcance «gasto».
400 max_cost_required / idempotency_key_requiredLas peticiones de pago llevan max_cost y Idempotency-Key (de 8 a 64 caracteres).
409 cost_exceeds_maxLa estimación supera tu max_cost: no se generó nada.
402 daily_cap_exceededAlcanzaste el tope diario del token (se reinicia a medianoche, hora de Madrid).
424 provider_key_missingFalta la key del proveedor: el error dice dónde conseguirla.
429 rate_limitedDemasiadas peticiones: espera lo que diga Retry-After.
