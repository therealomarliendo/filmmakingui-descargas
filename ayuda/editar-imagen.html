Editar imagen

Cambia una imagen con un prompt y, si quieres, con imágenes de referencia.

  1. Imagen a editar: súbela, elígela de una galería, extrae un fotograma de un vídeo o genera una nueva.
  2. Referencias: personajes o imágenes; su etiqueta («persona izquierda») se puede usar en el prompt.
  3. Modelo: cada uno admite un máximo de imágenes; GPT Image cobra cada imagen enviada.
  4. Proporción: «Igual que la original» usa la más parecida que admita el modelo.
  5. Prompt de edición (en inglés). «Ver el prompt que se enviará» muestra cómo se numera cada imagen.
  6. Opcional: aplica el estilo de un proyecto de animación.
  7. Editar muestra el coste. El resultado es una imagen nueva: la original nunca se sobrescribe.

Desde el resultado puedes ver antes/después, reportarlo o usarlo en Transformar vídeo (Motion control).
